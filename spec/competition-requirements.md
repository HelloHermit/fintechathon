## 要求对照

| 赛题项 | 当前计划 | 当前证据 |
|---|---|---|
| 至少三个场景 | 账单分析、订阅 / 代扣、模拟智能转账 | 离线代码链路已复演，真实模型HTTP401排错后另验收 |
| 自然语言、模糊表达与上下文 | 接真实模型，不以固定回答代替 | 未接入 |
| 权限分级 | 固定代码规则，按转账日累计区分黄 / 红 | 已实现、离线独立测试见docs/09 |
| 确认与强验证 | 绑定操作确认，红档不同身份因素验证 | 确认已实测；MFA未完成，红档拒绝 |
| 幻觉、注入、越权防御 | 数据来自工具，白名单 / 参数 / 归属检查 | 固定恶意候选/归属已测；真实模型另验收 |
| 决策 / 执行审计与熔断 | 追加日志、原子保存、三错锁十分钟持久化 | 已实现、离线故障及重启测试 |
| 受限可监控逻辑隔离环境 | 验证文件、网络和资源权限边界 | 未验证 |
| DAG 任务规划 | 有依赖关系的任务图，经代码检查后执行 | 候选控制器已测；真实模型规划未接通 |
| 中断、回退、人工接管 | 暂停等待确认、失败停止、只撤回可撤回修改 | 中断/接管/未提交事务回滚已测，补偿回退未完成 |
| APP、IM 等渠道联通 | 优先简单浏览器聊天窗口，正式渠道认可待核对 | CLI已实跑，浏览器/正式渠道未完成 |

转账阈值依据摘录黄色“日累计 ≤ 1000 元”，红档取补集“日累计 > 1000 元”。摘录红色比较符号丢失，正式提交前须核对。订阅查询 / 取消按摘录示例为黄色，动作细则读 `docs/01-permission-tiers.md`。不把旧“资金流出一律红档”当赛事规则。

口令加独立手机认证器是拟议强验证方案，主办方是否认可尚未核实。屏显随机码不等于多因子。模拟数据是否符合校内与正式业务验收需核对通知；展示必须明确标注模拟。
