# README · 订阅管理智能体

> 2026 第八届微众银行 FinTechathon · 人工智能赛道参赛作品

---

## 一句话介绍

**一个能用自然语言管理「订阅 / 自动扣款」的智能体，重点在权限控制。**

你说「我有哪些订阅」，它列给你；你说「把视频会员退了」，它会先告诉你退订的后果、要你输确认码，**才动手**。

---

## 核心设计：AI 有识别权，没有决定权

```
用户输入
  ↓
[代码] 注入关键词拦截 —— 命中即拒绝
  ↓
[模型] 只输出"用户想干什么"（一个固定的意图名）
  ↓
[代码] 查权限表：这个意图属于哪一档？
  ↓
🟢 绿色 → 直接执行
🟡 黄色 → 说清要做什么 → 等明确同意 → 执行
🔴 红色 → 告知不可逆后果 → 要 6 位确认码 → 验证 → 执行
  ↓
[代码] 全部写入审计日志（包括被拒绝的）
```

**为什么这么设计**：**模型是可以被说服的，代码不会。**
所以「这个操作危不危险」这件事，绝对不交给模型判断。

---

## 权限分级（依据：损失可逆性）

| 档位 | 判断标准 | 例子 | 执行方式 |
|---|---|---|---|
| 🟢 绿色 | 做错了没有任何后果 | 查订阅列表、查总额 | 不问，直接做 |
| 🟡 黄色 | 可以撤销，最坏是麻烦 | 改备注、暂停订阅、添加订阅 | 说清要做什么 → 等明确同意 |
| 🔴 红色 | **不可逆**或涉及资金 | 退订、续费支付、删账单 | 告知后果 → 要确认码 → 验证 |

详见 [`docs/01-permission-tiers.md`](docs/01-permission-tiers.md)

## 快速开始

```bash
# 1. 进入项目目录
cd fintechathon

# 2. 初始化数据库（建表 + 灌入示例数据）
python src/init_db.py

# 3. 启动
python src/main.py
```

**依赖**：Python 3.10+，只用标准库（`sqlite3`、`json`、`random`、`datetime`）。**不需要 pip install 任何东西。**

## 关于使用 AI 工具

**我们用了 AI 辅助生成代码，这一点不隐瞒。**

我们的规则是：
- 每一块代码，负责人必须**能不看代码讲 3 分钟**，并能**回答一个追问**——做不到就不算完成
- **写代码的人不能写自己的测试**——避免"用实现的漏洞验证实现"
- AI 生成的每一行都要能解释。**解释不了的代码不许用**
