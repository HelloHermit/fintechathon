## 0. 先看结论

- **录制电脑是 Windows**（队长 11-01 确认）。所以第 13 镜头“沙箱分析”**不录**（Windows 上沙箱没有网络隔离，界面会如实显示“网络隔离降级”），台词卡第 12 句也不用说。
- **成片目标 4 分 48 秒左右**（上限 5:00），14 个镜头，口播约 1000 字。第 14 镜头加了“全部回退”（11-01 根据外部审查建议补的：把一次确认 → 到点执行 → 回退未执行部分 → 已执行订单不自动退款这条链完整演出来）。
- **用回放模式录**（`python run.py --reset --model replay`）：回放的是真实大模型（deepseek-flash）事先录好的输出，每次结果一模一样，不联网、不用密钥。会话 C 已在回放模式下用真实浏览器把下面的操作**完整走过一遍：每一步都正常，控制台 0 错误**。
- **回放模式有三条铁律**（违反任何一条，后面每一句都会显示“抱歉，智能助手暂时连不上”）：
  1. **只说台词卡上的话（Windows 上是前 11 句），按顺序，逐字一致**——第一句必须是“你好呀”（剪辑时剪掉），标点也要一样，所以**一律复制粘贴，不要手打**。台词已单独存成 `deliverables/答辩准备/素材/台词卡.txt`，用记事本打开就能逐行复制。
  2. **只在台词卡标了“点确认 / 强验证”的地方点按钮**。在最后一句话说完之前，**不要点**任何别的确认、取消、快捷回复小按钮、首页提醒上的按钮、异常卡片上的“冻结”、问卷“提交测评”。
  3. **快进时间、看计划、看审计放在最后**。快进之后不能再和小安说话。
- **飞书镜头（可选）**：据队长 11-01 的任务书，飞书真机已验证**绑定、私聊、小额卡片确认**三项。如果队长手里有真机录屏，可以剪一段 ≤ 20 秒（私聊说一句小额转账 → 飞书卡片 → 点卡片上的确认），**替换第 8 镜头（账单分类）**，总长不变。只放这三项，**不要演红档**（红档在飞书只生成待办、回 App 验证，真机是否走过这条要队长确认）。飞书要用真实模型，不能用回放。
- **旧视频不要提交**：旧的 `演示视频.mp4`（2:56）在 00:43–00:52 的字幕说“调用模型之前就被代码拦下”，说法过头；新视频录好后覆盖它，旧字幕文件 `演示视频字幕.srt` 一起删掉或替换。

## 1. 录制前检查清单

**电脑与程序**

- [ ] 录制电脑：**Windows**。需要 Python 3.11 或更新版本（在 PowerShell 里输入 `python --version` 查看）。这台电脑上还没跑通过 `python run.py` 的话，先跑一次；报错就把终端截图发给会话 C。
- [ ] `git pull` 拿到最新 main（回放录制文件在 `cassettes/` 里，要是最新的）。
- [ ] 打开 **PowerShell**（开始菜单搜“PowerShell”），用 `cd` 进到项目文件夹（例如 `cd D:\fintechathon`，按你们实际的路径），运行：

```bash
python run.py --reset --model replay
```

- [ ] 终端里看到“模型：deepseek-flash（回放录制）”和“演示交易密码：135790”。
- [ ] 如果提示“python 不是内部或外部命令”，把命令开头的 `python` 换成 `py` 再试；还不行就是没装 Python 或没加到 PATH。
- [ ] 如果 Windows 弹出防火墙提示问是否允许 Python 访问网络：选哪个都不影响（服务只在本机 127.0.0.1 上）。
- [ ] 录完要停掉服务：在 PowerShell 窗口里按 Ctrl+C。
- [ ] 端口被占用时换端口：

```bash
python run.py --reset --model replay --port 8766
```

**浏览器**

- [ ] 用 Chrome **无痕窗口**（Ctrl+Shift+N）打开 `http://127.0.0.1:8765`（无痕可以避开旧缓存和浏览器插件）。
- [ ] 按 F11 全屏，隐藏地址栏和书签栏。
- [ ] 调缩放（Ctrl + 加号 / 减号）：让**手机外框**和**右侧三块面板**（演示控制、安全透视、模拟手机·短信）**同时完整出现在屏幕上、不用滚动**。会话 C 实测，等效 1280×720 的画面字最清楚。先看 Windows 的系统缩放（设置 → 系统 → 屏幕 → “缩放”），1920×1080 的屏幕按下表设浏览器缩放：

  | 125% | 110%（想让字更大可试 125%，以三块面板都完整显示、不用滚动为准） |
  | 100% | 150% |
- [ ] 右侧“演示控制”里能看到 **“模型：回放”** 标签。看不到就说明启动时没加 `--model replay`，停掉重来。
- [ ] 点一次 **“重置演示库”**，再按 F5 刷新。首页显示“早上好，陈雨桐”、总资产 ¥96,698.00，右下“模拟手机·短信”是空的。

**桌面与声音**

- [ ] 打开 Windows 的“勿扰”（Windows 11：设置 → 系统 → 通知 → 勿扰；Windows 10：右下角操作中心 → 专注助手 → 仅闹钟），关掉微信、QQ、邮件等所有通知。
- [ ] 关掉无关窗口和浏览器标签；桌面上不要露出私人文件。
- [ ] 用记事本打开 `deliverables/答辩准备/素材/台词卡.txt`。有第二块屏幕就放在那边；只有一块屏幕就录制时 Alt+Tab 切过去复制，剪辑时剪掉切换画面。
- [ ] 录屏软件（三选一）：
  - **OBS Studio**（免费，推荐）：来源选“显示器采集”，设置 → 视频里输出分辨率 1920×1080、30 帧，录制格式选 MP4。录整个屏幕，Alt+Tab 切到记事本也能录到（剪辑时剪掉）。
  - **Xbox Game Bar**（系统自带）：Chrome 全屏后按 Win + Alt + R 开始 / 停止。它只录当前这个窗口，切到记事本时那段不会录进去，正好省得剪。
  - Windows 11 的**截图工具**也有“录制”按钮，可以框选整个屏幕录。
  - 先试录 10 秒，检查画面清晰、没有录进通知。

**怎么录（推荐“先画面、后配音”）**

1. **先只录画面**：按第 2 节的操作步骤，从头到尾一口气走完（约 5–6 分钟，不用说话）。录 2 遍，挑好的一遍。
2. **再配音**：找安静的房间，用手机或耳机麦克风，按每个镜头的“口播原文”分段录。
3. **剪辑**（剪映专业版 Windows 版即可，或 Windows 11 自带的 Clipchamp）：按第 2 节的时间把画面和配音对齐；剪掉“你好呀”、等待、切换窗口的片段；用“识别字幕”自动生成字幕后**逐句核对数字**；每个镜头左上角加一个小标签写“评分点”那一列（例如“安全合规 · 诱导转账”），方便评委对照评分表。
4. **导出**：1080p、MP4（H.264），时长 ≤ 5:00，覆盖 `deliverables/演示视频.mp4`。文件大小和格式按大赛要求（需要队长确认大赛的上限）。

## 4. 出错应对

| 现象 | 原因 | 怎么办 |
|---|---|---|
| 小安回复“抱歉，智能助手暂时连不上（已自动重试一次）” | 这句话或之前的操作和录制时不一样：打错字、少了“你好呀”、顺序错、中途多点了别的按钮、刷新过页面 | 点右侧 **“重置演示库”** → F5 刷新 → 从“你好呀”重新开始（重置会同时清空小安的对话记忆）。录一整遍只要 5–6 分钟，直接重录比修补快 |
| 右侧没有“模型：回放”，或显示真实模型 / 未配置 | 启动时没加 `--model replay` | 终端按 Ctrl+C 停掉，重新运行 `python run.py --reset --model replay` |
| 交易密码或动态码输错 | 手滑 | 直接再输一次正确的即可（会话 C 实测：错一次再输对，后面的回放照常）。连错 3 次会锁 10 分钟（这是熔断功能）：点“重置演示库”即可解锁，然后从头重录 |
| 点“获取动态码”后提示 60 秒内不能重发 | 刚刚点过一次 | 用已经收到的那条短信里的码；或等倒计时结束 |
| 确认单上提示“确认码已失效”或已过期 | 打开确认单后刷新了页面，或停留超过 5 分钟 | 不要在确认单打开时刷新；出现了就重置从头来 |
| 手机顶部的短信横幅挡住了内容 | 收到短信时横幅会停 9 秒 | 等它自己消失再操作下一步 |
| 快进后看到“扣费失败”之类的提示 | 快进前点过“冻结”卡片 | 重置从头来；冻结卡不要在视频里演（异常镜头里口头说“还能一键冻结”就够了） |
| 页面样式乱、按钮点了没反应 | 浏览器缓存了旧版本 | 用无痕窗口；或 Ctrl+Shift+R 强制刷新 |
| 端口被占用（启动时报错） | 上次没关掉 | 换端口：`python run.py --reset --model replay --port 8766`，浏览器打开 8766 |
| 沙箱卡片写着“网络隔离降级” | Windows 上没有 Linux 的网络命名空间，资源限制也只剩 5 秒超时和语法树白名单 | 正常现象（界面如实标注）。Windows 录制本来就不录第 13 镜头；如果不小心说了第 12 句，剪掉这段即可 |
| 点“全部回退”没反应 | 这个按钮要连点两次防误触：第一次变成“再点一次：取消未执行步骤并释放预算”，4 秒内不点就恢复原样 | 4 秒内再点一次 |
| PowerShell 里中文显示成乱码 | 终端字体或编码问题 | 不影响网页和录制，可以忽略；只要浏览器能打开页面就行 |
| 录完发现超过 5 分钟 | — | 按第 2 节末尾的顺序删镜头；不要加快语速到听不清 |
