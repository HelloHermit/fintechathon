# 演示数据规格 · rich seed v1

用途：会话 A 按本文件生成演示库（确定性、可一键重置）；会话 B 按本文件写评测用例的期望值。

- 表格里写明的数值、名称、日期必须一致。写“约”的由 A 决定，并在 `docs/sprint/status-A.md` 公布最终值。
- 所有人名、手机号、账户、商户均为虚构。手机号使用 `1380000xxxx` 等明显虚构号段。
- 旧的三场景测试数据（alice-main 10000 元等）保留为 `legacy` 种子，只给旧测试用；网页和评测默认使用本文件的 `rich` 种子。

## 1. 模拟时间

- 重置演示库后，模拟时间 = **2026-10-30 09:00:00 +08:00（周五）**，之后随真实时间流逝。
- 演示接口可以快进时间（见 API_V2「演示接口」）。快进时由调度器执行到期的定时任务。
- “今天、本月、上个月、今年”一律按模拟时间计算。界面状态栏显示“模拟时间”。

### 风险测评（固定题目与计分）

6 道题，每题 5 个选项，依次计 1–5 分；总分 6–30。

| 题 | 题目 | 选项（1 分 → 5 分） |
|---|---|---|
| Q1 | 投资经验 | 无 / 1 年以内 / 1–3 年 / 3–5 年 / 5 年以上 |
| Q2 | 能接受的最大亏损 | 不能亏 / 5% 以内 / 10% 以内 / 20% 以内 / 20% 以上 |
| Q3 | 计划投资期限 | 3 个月内 / 3–6 个月 / 6–12 个月 / 1–3 年 / 3 年以上 |
| Q4 | 收入稳定性 | 无稳定收入 / 不太稳定 / 一般 / 稳定 / 很稳定 |
| Q5 | 投资目的 | 保本 / 稳定增值 / 平衡 / 较高收益 / 高收益 |
| Q6 | 理财资金占总资产比例 | 70% 以上 / 50–70% / 30–50% / 10–30% / 10% 以下 |

等级：6–9 分 C1 保守型、10–14 分 C2 稳健型、15–20 分 C3 平衡型、21–25 分 C4 成长型、26–30 分 C5 进取型。适当性规则：只能申购风险等级 ≤ 对应 R 级的产品（C3 → 最高 R3）。有效期 1 年。
