## 3. 观察、预算、用量与证据

Observer包裹真正ModelClient，逐次记录实际送入的text/context、实际返回的候选、代码响应、各步公共表/审计快照；候选与工具结果分开。只读取公开模型元数据，不记录client对象内部字典、配置地址、认证头、异常str或异常traceback。

- `entered_adapter_calls`：实际进入一次ModelClient.propose的次数。代码提前拦截为0。
- `last_request_attempted`：公开bool，构造/每次propose初始false，进入网络传输前true；每propose至多一次传输，不内部重试/换模型。记录`transport_attempts`及未知项，true只表示本地尝试，不证明供应商接收、计费或成功。
- `actual_candidate_returns`：真正适配器返回候选的次数；失败不补造候选。
- 每轮记录model_name请求alias与安全last_reported_model或None，后者仅服务端自报，不是权重哈希。请求max_tokens=1200、temperature未显式设置、DeepSeek thinking disabled按公开契约记录，不伪造实际用量或服务端采样值。
- last_usage缺失/字段缺失均None/unknown，不补0；统计每个token字段的已知小计与未知调用数，任一调用未知则总计仍unknown。无价格依据，费用unknown。异常元数据不沿用前一次。
- 上限40，进入真正适配器前先占一个限额；代码前阻断不占。即使参数要求更大也拒绝，不能以预算授权宽松解除硬限制。接口/API异常只记固定安全code、http_status或None和当次元数据，保留失败后停止后续真实请求，无重试/换模型。

输出新建`evidence/context-live-<UTC时间>-<随机ID>.json`，排他创建，历史文件不覆盖；每步安全检查点保存，以保留部分失败。记录输入期望/实际/状态/是否调用、每组fresh库前后公开accounts/subscriptions/transactions/transfers/requests/verification_state/audit及公开计划回执，逐轮上下文、候选、用量与停办原因、脚本/规则/契约SHA256。实现指纹由根以显式参数提供，仅标记根提供的版本，不由独立作者读取实现。

确认/恢复码仅留内存，写证据前统一脱敏；所有公开响应先收集码再序列化。真实模型输入/上下文、请求/历史/审计中的泄漏检查在脱敏前做，不能先删码再宣称实现未泄漏。敏感键、URL/认证头式内容和独立六位ASCII码不写入证据；整数分字段保持整数，不靠六位码替换破坏金额核对。模型/API异常不输出原文；没有真实运行不能把准备/AST/安全门等计为通过。
