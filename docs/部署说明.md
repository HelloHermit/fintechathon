# 部署说明

**结论**：只需要 Python 3.11 或更高版本，不用安装任何第三方库。全新克隆后 3 条命令就能在浏览器里用：

```bash
git clone https://github.com/HelloHermit/fintechathon.git
cd fintechathon
python run.py
```

然后浏览器打开 <http://127.0.0.1:8765>。全部账户、资金、商户、短信都是**模拟数据**。

> 没有配置模型密钥时，页面能打开，账单、卡片、审计等数据页面都能看，但和“小安”对话会提示模型不可用。配置方法见下面第 2 步。想先看界面，也可以打开 <http://127.0.0.1:8765/?mock=1>（浏览器内置的假数据，不需要密钥）。

---

## 1. 准备 Python

| 系统 | 怎么装 | 怎么确认 |
|---|---|---|
| Windows 10/11 | 到 <https://www.python.org/downloads/> 下载 3.11 以上版本安装，安装时勾选 **Add python.exe to PATH**；或在 PowerShell 里运行 `winget install Python.Python.3.12` | PowerShell 里运行 `python --version`，显示 3.11 以上 |
| macOS | `brew install python@3.12`（需要先装 Homebrew），或从 python.org 下载安装包 | 终端运行 `python3 --version` |
| Linux（Ubuntu/Debian） | `sudo apt install python3`（Ubuntu 22.04 以上自带 3.10/3.12；需要 3.11 以上） | `python3 --version` |

macOS 和 Linux 上命令是 `python3`，下文的 `python` 都换成 `python3`。

我们实测过的版本：Python 3.11、3.12（可以编译和启动）、3.13（开发和全部测试所用版本）。

## 2. 配置模型密钥

小安用 DeepSeek 大模型理解和规划（模型只负责“提议”，权限、确认、执行都由代码决定）。在项目根目录建一个名为 `.env` 的文件（已被 Git 忽略，不会被提交），内容：

```
FINTECH_MODEL_BASE_URL=https://api.deepseek.com
FINTECH_MODEL_NAME=deepseek-flash
FINTECH_MODEL_API_KEY=你的密钥
```

也可以不建文件，直接设置环境变量：

- Windows PowerShell：`$env:FINTECH_MODEL_API_KEY="你的密钥"`
- macOS / Linux：`export FINTECH_MODEL_API_KEY=你的密钥`

**不要**把密钥写进代码、提交到仓库或发到聊天里。

## 3. 启动与常用参数

```bash
python run.py                 # 启动，默认 http://127.0.0.1:8765
python run.py --reset         # 先按演示数据规格重建演示库，再启动
python run.py --port 8766     # 端口被占用时换一个
python run.py --model replay  # 回放录制好的模型回复（不需要密钥；只能复现录制过的对话，需要仓库里有 cassettes/ 录制文件）
```

- 演示库文件在 `data/demo.db`。演示时间从 **2026-10-30 09:00（模拟时间）** 开始，随真实时间流逝；页面右侧（手机上在“我的 → 演示控制”）可以快进时间、重置演示库、切换演示身份（陈雨桐 / 王磊）。
- 红档操作（大额转账、理财申购、卡挂失等）需要**演示交易密码 `135790`** 和**模拟短信动态码**。动态码在页面右侧“模拟手机 · 短信”里（手机上在“我的 → 模拟手机短信”），不会出现在对话里。
- 停止：在启动的终端里按 `Ctrl+C`。

## 4. 用 Docker 部署（可选）

适合部署到云服务器，或者不想在本机装 Python 的情况。需要先安装 Docker Desktop（Windows / macOS）或 Docker Engine（Linux）。

```bash
export FINTECH_MODEL_API_KEY=你的密钥          # Windows PowerShell：$env:FINTECH_MODEL_API_KEY="你的密钥"
docker compose up --build
```

浏览器打开 <http://localhost:8765>。演示库放在名为 `xiaoan-data` 的卷里，重建容器后失败锁定、审计记录仍在。

注意：

- 服务会检查浏览器地址栏里的“主机:端口”（防止别的网站冒用）。如果把端口映射改成别的（例如 `"8080:8765"`），或者用服务器 IP / 域名访问，需要设置 `FINTECH_ALLOWED_HOSTS`，例如 `FINTECH_ALLOWED_HOSTS=localhost:8080,203.0.113.5:8765`。
- 容器用非 root 用户运行，不包含测试、文档和证据文件（见 `.dockerignore`）。
- 不用 compose 时：`docker build -t xiaoan .`，然后 `docker run --rm -p 8765:8765 -e FINTECH_MODEL_API_KEY=你的密钥 -v xiaoan-data:/data xiaoan`。
- 如实说明：开发所用的云端环境没有 Docker 守护进程，Dockerfile 和 compose 文件**没有在云端实际构建过**；镜像里运行的命令（`FINTECH_HOST=0.0.0.0 python run.py`）已在本机用 Python 3.11 验证能启动并返回首页。

## 5. 运行测试与评测

```bash
python -m unittest discover -s tests -p "test_*.py"   # 单元测试（需要 Docker 的一组在没有 Docker 时会报错，属预期）
python bench/run_bench.py --start                     # 黑盒评测 151 条，需要模型密钥，约 15–20 分钟
```

评测报告生成在 `bench/reports/latest.md`，说明见 [bench/README.md](../bench/README.md)。

## 6. 常见问题

| 现象 | 原因与处理 |
|---|---|
| `端口 8765 无法使用` | 端口被占用：`python run.py --port 8766`，然后访问 <http://127.0.0.1:8766> |
| 页面显示“连接不上后端” | 后端没启动，或启动的终端被关掉了 |
| 对话回复“模型不可用” | 没有配置 `FINTECH_MODEL_API_KEY`，或网络连不上 `api.deepseek.com` |
| 用服务器 IP 或域名访问时，页面能打开但操作都失败（HTTP 403） | 服务只信任 `127.0.0.1` / `localhost`，按第 4 节设置 `FINTECH_ALLOWED_HOSTS` |
| 想从头再演示一遍 | 页面里“重置演示库”，或 `python run.py --reset` |
| Windows 上 `python` 打开了应用商店 | 安装 Python 时没勾选 PATH；重新安装并勾选，或用 `py run.py` |
