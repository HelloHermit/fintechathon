运行器只输出方法状态，捕获业务偶发 stdout/stderr，不显示源码回溯或完整响应。失败只保存脱敏错误类型及断言原因。每次实际执行向 JSON 的 `attempts` 追加首轮或复测记录，包含退出码、耗时、实际 methods/subtests、输入/期望/实际/验证方法/不确定处，以及运行前后源码 SHA256；实现文件仅按字节计算 hash，不解码或检查内容。首轮失败不得删除、覆盖或降低期望。

旧 replay 的测试夹具具体为 `user_id/step/code/used_at`，主键是三列 `user_id/step/code`，包含同一用户同一步两个合成 code 行，核对迁移只留下用户/步/时间并折叠重复步、保留业务/审计/失败状态。没有公开的迁移存储故障注入口，正常迁移测试不代表全部 DDL 中间故障、全部历史表变体、外部备份或 SQLite 空闲页取证清除已验证。

CLI 自动运行只通过标准库模拟 `input/getpass/sys.argv` 与三流 `isatty` 并在内存捕获输出，不读取脚本私有函数。它能核对固定同意、因素使用 getpass 和取消不读因素；**不能证明真人终端确实无回显、本人完成登记或手机是独立设备**。真人登记、独立手机持有证明、一次性显示和真实终端无回显全部未运行；不把合成登记算成真人通过。
