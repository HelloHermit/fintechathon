# 飞书接入说明（给队长：一步步建飞书机器人）

**结论**：在飞书开放平台建一个“企业自建应用”，打开机器人能力，用**长连接**接收消息（不需要公网地址、不需要服务器），拿到 App ID 和 App Secret 写进本机 `.env`，然后用 `python run.py --feishu` 同时启动网页和机器人。整个过程约 20 分钟，需要你所在飞书组织的管理员审核发布（自己建的个人/测试企业里，你自己就是管理员）。

> 全部账户、资金、短信都是模拟数据。飞书机器人只是另一个“渠道”，和网页共用同一个模拟账本。

## 0. 飞书里能办什么（渠道分级风控）

| 档位 | 网页 App | 飞书私聊 |
|---|---|---|
| 绿档（查询、账单、报告） | 直接办 | 直接办 |
| 黄档（小额转账、冻结卡、取消订阅…） | 确认按钮 | 飞书卡片上的“确认 / 取消”按钮；聊天里打“确认”不算 |
| 红档（大额转账、解冻、申购…） | 交易密码 + 短信动态码 | **只生成待办**，提示“请在 App 内完成强验证”；动态码绝不发到飞书 |

另外：只处理和机器人的**私聊**，群聊一律忽略；没有绑定的飞书用户只能看到使用说明，不能办任何业务。

## 1. 创建企业自建应用

1. 用浏览器打开飞书开放平台 <https://open.feishu.cn/app>，用你的飞书账号登录。
2. 点“创建企业自建应用”，名称填“小安（模拟银行）”，描述填“FinTechathon 参赛演示，全部数据为模拟”，图标可以用仓库里的 `src/web_assets/icons/icon-512.png`。
3. 创建后进入应用详情页。

## 2. 打开机器人能力

左侧“添加应用能力” → 找到“机器人” → 添加。

## 3. 开通权限

左侧“权限管理” → 搜索并开通以下权限（名称以开发者后台显示为准）：

| 权限 | 用途 |
|---|---|
| `im:message`（获取与发送单聊、群组消息） | 收发消息 |
| `im:message:send_as_bot`（以应用的身份发消息） | 机器人回复、主动推送提醒 |
| `im:message.p2p_msg:readonly`（读取用户发给机器人的单聊消息） | 只接收私聊 |

**不需要**开通读取群聊全部消息、通讯录等其他权限——权限越少越安全。

## 4. 先在本机启动机器人（长连接要求）

飞书后台保存“长连接”方式时，会检查你的程序是否已经连上，所以要**先启动程序，再回后台保存**：

1. 打开左侧“凭证与基础信息”，复制 **App ID** 和 **App Secret**。
2. 在项目根目录的 `.env` 里加两行（这个文件不会提交到仓库）：

   ```
   FEISHU_APP_ID=cli_xxxxxxxxxxxxxxxx
   FEISHU_APP_SECRET=xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
   ```

3. 安装飞书官方 SDK（只有飞书渠道需要，核心程序仍只用 Python 标准库）：

   ```bash
   pip install -r requirements-feishu.txt
   ```

4. 启动：

   ```bash
   python run.py --feishu
   ```

   终端里看到“飞书：机器人已通过长连接启动（只处理私聊；红档需回到 App 完成强验证）”即可。如果提示“没有设置 FEISHU_APP_ID / FEISHU_APP_SECRET”或“没有安装 lark-oapi”，按提示补上。

**不要**把 App Secret 发到聊天、截图或提交到仓库；如果泄露，在“凭证与基础信息”里重置。

## 5. 订阅事件和卡片回调（用长连接）

左侧“事件与回调”：

1. **事件配置** → 订阅方式选“**使用长连接接收事件**” → 保存（此时第 4 步的程序必须在运行）。
2. 点“添加事件”，搜索并添加 **接收消息 `im.message.receive_v1`**。
3. **回调配置** → 订阅方式同样选“使用长连接接收回调” → 添加 **卡片回传交互 `card.action.trigger`**（用户点卡片上的“确认 / 取消”按钮时触发）。

## 6. 发布版本

左侧“版本管理与发布” → “创建版本” → 版本号填 `1.0.0`，“可用范围”选你自己（或你的队友），填写更新说明 → 保存 → “申请线上发布”。管理员审核通过后才生效。自己是管理员时，在飞书管理后台的“应用审核”里通过即可。

## 7. 在飞书里绑定并试用

1. 浏览器打开 <http://127.0.0.1:8765>，进入“我的 → 绑定飞书”，点“生成绑定码”，得到 6 位数字（5 分钟有效、只能用一次）。
2. 在飞书里搜索“小安（模拟银行）”，私聊它，发送 `绑定 123456`（换成你的绑定码）。网页会自动显示“已绑定”。
3. 试几句：
   - “这个月花了多少”（绿档，直接回复）
   - “给小王转200”（黄档，回复一张带“确认 / 取消”按钮的卡片；在聊天里打“确认”不会执行）
   - “给妈妈转2000”（红档，飞书只回复“请在 App 内完成强验证”；网页顶部会出现“来自飞书的待办”，在网页里输入交易密码和短信动态码完成）
   - 在群里 @ 机器人（应当没有反应：只处理私聊）
4. 演示视频需要飞书镜头的话，用手机录屏这几步，发给负责视频的同学剪进去（总时长仍 ≤ 5 分钟）。

## 8. 常见问题

| 现象 | 处理 |
|---|---|
| 后台保存长连接时报“未检测到连接” | 先运行 `python run.py --feishu`，确认终端没有报错，再保存 |
| 机器人不回复 | 检查：应用是否已发布且你在可用范围内；事件是否订阅了 `im.message.receive_v1`；`.env` 的 App ID / Secret 是否正确；是不是在群里发的（群聊会被忽略） |
| 点卡片按钮没反应 | 检查“回调配置”是否用长连接并添加了卡片回传交互 |
| 提示“请先绑定” | 按第 7 步在网页生成绑定码并在飞书发送 |
| 想解除绑定 | 网页“我的 → 绑定飞书 → 解除绑定” |

## 9. 安全说明

- 飞书账号被盗时，攻击者最多能做绿档查询和黄档小额操作（仍需点卡片按钮，且受当日 ¥1,000 小额额度和反诈评分约束）；任何红档操作都必须回到 App 输入交易密码和动态码。
- 机器人只认已绑定的飞书用户；绑定码一次性、5 分钟过期。
- 卡片按钮的回调携带服务端生成的确认凭据，伪造一条“确认”文字消息无效。
- 群聊消息一律忽略，避免他人在群里替你下指令。
- App ID / Secret 只从环境变量读取，不进仓库、不进日志。
